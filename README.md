# 승급의 계단

회사 빌딩의 계단을 오르는 웹 브라우저 게임입니다. "구조조정까지 남은 일수"가 바닥나기 전에 계단을 오르고, 날아오는 업무와 계단의 장애물을 막거나 피하며 100층까지 오릅니다.

## 하기

`demo_api/index.html`을 Chrome·Edge 등 브라우저로 엽니다 (설치·서버 필요 없음). 소리는 첫 키 입력이나 클릭 뒤부터 납니다.

| 조작 | |
|---|---|
| ← → | 다음 계단 방향으로 한 칸 오르기 (거꾸로 칸에서는 반대 키) |
| Q · E | 왼쪽 · 오른쪽 막기(패링) — 종이비행기 편대는 누르고 있기 |
| Esc | 일시정지 · 뒤로 |
| 방향키 · Enter · Space · 마우스 | 메뉴 고르기 · 결정 |
| Enter · Esc · Space · 클릭 | 컷신 건너뛰기 |

## 게임

- **보통 모드 (업무 시작)**: 1층에서 100층까지. 판을 시작할 때마다 짧은 시작 컷신, 100층에 오르면 엔딩 컷신 뒤 결과 화면
- **무한 모드**: 1층부터 모든 장애물, 끝없이 오르며 최고 층을 따로 기록
- **연습 모드**: 계단을 오르지 않고 서서 막기만 연습 (게임 오버 없음, 막은 수·맞은 수를 셈)
- **결과 화면**: 다시 하기 · 기록 공유(이미지 저장) · 로비로
- **컷신**: 켤 때 인트로 (야근 → "구조조정까지 D-30" 통보 → 분노 → 창가에서 꼭대기를 노려봄 → 제목), 새 판 시작, 100층 엔딩 (CEO 책상 위 버튼을 누름 → 빌딩 폭발 → 책상에서 깨어남)
- **장애물 보기**: 설정(톱니바퀴) → 장애물 · 보기, 또는 조작법 화면에서. 24장면을 실제 규칙으로 보여 주며 맞는 키를 맞는 순간에 누른다

### 장애물

| 막는 것 | 결재판, 경쟁 사원, 모니터, 전화기, 서류, 포스트잇(여러 번), 서류가방, 스테이플러(되돌아옴), 종이비행기 편대(누르고 있기), 편지 3연발(박자에 맞춰), 튀어 내려오는 의자(가만히 서서 막기) |
|---|---|
| 막으면 안 되는 것 | 커피 |
| 계단 | 금 간 계단(오래 서 있으면 무너짐), 젖은 계단(전기가 흐를 때 감전), 내려가는 에스컬레이터, 사라지는 칸, 거꾸로 칸 |
| 그 밖 | 상사의 눈(레이저가 지나갈 때 오르면 들킴), 카메라 플래시(눈부심만) |

- 경쟁 사원도 계단 장애물을 겪습니다: 사라지는 칸·전기 앞에서 기다리고, 금 간 칸·젖은 칸에서 떨어지거나 감전되며, 상사의 눈 레이저가 지나갈 때 움직이면 들켜서 실격됩니다
- 즉사 장애물은 위험할 때 또렷하게 보입니다: 전기는 번개와 불꽃(흐르기 직전 노란 테두리), 금 간 칸은 붉은 금이 퍼짐, 사라지는 칸은 직전 번쩍임과 없어진 뒤 붉은 점선

### 그림과 소리

- 스프라이트는 4배 밀도(`pixel_scale` 4)의 32비트 느낌 픽셀 아트, 컷신은 2배 밀도 픽셀 아트
- 효과음은 장애물마다 다르고, 음악은 20층 구간마다 바뀝니다

### URL 매개변수

`?seed=7` 난수 고정 · `?bot=1` 자동 플레이 · `?mute=1` 소리 끔 · `?nointro=1` 인트로 건너뜀 ·
`?demo=<장면 id>` 장애물 보기 장면 바로 열기 · `?cs=<intro|runstart|ending>&cst=<초>&csfreeze=1` 컷신의 한 순간에 멈춤 (QA용)

## 폴더

| 폴더 | 내용 |
|---|---|
| `demo_api/` | 게임 (`index.html`, `game.js`, `assets/`) |
| `tools/qa/` | QA 검사기 — `python tools/qa/run_all.py` 로 모두: 움직임·상호작용, 스프라이트, 애니메이션, 팔·손 해부학, 컷신 대본, 단위 테스트, 에이전트 QA(Developer·Designer·Publisher 동작 확인·화면 대조). 장애물 갤러리 `hazard_gallery.py` |
| `tools/sprites/` | 스프라이트 만들기: 16비트 원본(`src16/`) → 팔·손 고치기(`fix_arms.py`) → 32비트(`upgrade32.py`) |
| `tools/cutscenes/` | 컷신 그림·소리 만들기, 컷신 갤러리 |
| `stairs_agents/`, `prompts/`, `.claude/agents/` | 게임을 만드는 에이전트 파이프라인 (Mechanics, Designer, Developer, Publisher와 QA). `python -m stairs_agents run --replay replay_api` |
| `docs/` | 기획서(`GDD.md`), 에셋 목록 등 |
| `agent_map/` | 에이전트 맵, 에이전트별 코드·빌드 그림 |
| `tests/` | 단위 테스트 (`python -m pytest tests`) |

준비: Python 3.10 이상, `pip install -r requirements.txt`, `playwright install chromium`, ffmpeg(소리 변환), Node.js(검사기).
